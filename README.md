# Hearthbound

A local-first D&D character ledger for creating heroes, editing full sheets, and updating vitals during sessions.

## Features

- **Create** — guided wizard for identity, abilities, skills, and details
- **Sheet** — combat stats, skills, inventory, spells, and story notes
- **Session Mode** — quick HP damage/heal, temp HP, conditions, death saves, rests
- **Roster** — manage multiple characters (saved in `localStorage`)

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
